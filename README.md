# variance-estimation-time-use-survey-2024
# Variance Estimation Methods — Time Use Survey 2024

## Project Overview
Master's Dissertation — MSc Survey Research and Data Analytics
International Institute for Population Sciences (IIPS), Mumbai

## Research Objective
To evaluate sampling errors and compare variance estimation 
methods using data from the Time Use Survey 2024.

## Methods Applied
### Design-Based Methods
- Taylor Linearization
- Jackknife
- Bootstrap

### Model-Based Methods
- Weighted Least Squares (WLS)
- Bootstrap WLS

## Key Indicators Used
- Standard Error
- Confidence Intervals
- Design Effect (DEFF)
- Relative Standard Error (RSE)

## Significance
Highlights importance of variance estimation methods in 
improving reliability of estimates for policy research.

## Tools Used
- Stata
- SPSS
- R
